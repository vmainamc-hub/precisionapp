## Purpose

This document outlines specific technical questions regarding integrating the official Deriv DBot / Blockly strategy ecosystem into a third-party trading platform.

---

## Questions for Deriv Developer Support

### 1. Blockly Workspace & Component Distribution
* Does Deriv provide an official standalone npm package (or ES module) for embedding the visual **Blockly workspace** with Deriv block definitions into third-party React applications without pulling the entire `deriv-app` monorepo?
* If third-party developers construct a Google Blockly workspace using Deriv's standard block definitions (`trade_definition`, `before_purchase`, `during_purchase`, `after_purchase`), is this officially recognized as compliant with Deriv DBot standards?

### 2. Strategy XML Format & Schema Specification
* Is there an official XSD / JSON schema or formal documentation for the **Deriv DBot XML format** generated by [bot.deriv.com](https://bot.deriv.com)?
* Are there any planned structural changes or schema migrations for DBot XML strategy files that developers should account for in upcoming API v3 releases?

### 3. Execution Runtime & Interpreter Guidance
* In the official `deriv-com/trading-bot-template`, strategy execution uses `bot-skeleton` with a client-side JavaScript interpreter. Does Deriv officially recommend this architecture for third-party automated bot execution over WebSocket API v3?
* Are there specific rate limits or concurrency constraints when a user runs an automated bot strategy sending `proposal` and `buy` requests over WebSocket API v3?

### 4. Licensing, Branding & Partner App Requirements
* What specific branding, attribution, or disclaimers does Deriv require when a third-party application provides an integrated DBot-compatible Blockly workspace?
* Are third-party applications permitted to offer one-click strategy presets (e.g. Martingale, D'Alembert) that load standard Deriv Blockly XML into the workspace?

### 5. App Builder vs. Standalone API Integration
* When building a comprehensive multi-feature trading platform (combining manual trading, digit analytics, and bot automation), does Deriv require using the App Builder starter template, or is integrating via a registered OAuth `App ID` and WebSocket API v3 fully supported?
